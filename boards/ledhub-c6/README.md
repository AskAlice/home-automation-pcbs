# ledhub-c6 — all-in-one display LED controller (80 × 50 mm)

ESP32-C6-WROOM-1 based LED controller with 2.8" ILI9341 TFT, EC11 rotary
encoder, 5-way ADC-ladder nav buttons, INMP441 I2S microphone, SHT31 +
BH1750 environmental sensors, LD2450 mmWave radar header, and a 5 V
level-shifted WS2812 output (74AHCT125 + 470 Ω).

**Primary firmware: WLED 0.15+** (ESP32-C6 supported since 0.15) with
`firmware/wled-usermod-ledhub/`. ESPHome is also possible — see
`esphome/ledhub-c6.yaml` (draft covering display, encoder, ADC buttons,
I2S mic, I2C sensors, LD2450 UART, RMT LED strip).

License: MIT. KiCad 8 project, generated by `gen_ledhub_c6.py`
(`python3 gen_ledhub_c6.py`; exits non-zero on any validation problem).

## Features

- USB-C power + native USB-Serial-JTAG flashing (GPIO12/13 via 22 Ω,
  5.1 kΩ CC pull-downs)
- AP2112K-3.3 LDO (VBUS → +3V3), logic 5 V rail `+5V` from VBUS via R20 0R
- Separate `LED_5V` input terminal (J4, 5.08 mm) powering the LED strip
  only; LED data out on J3 (LED_5V / DATA / GND)
- 74AHCT125 (U5, SOIC-14, VCC=+5V, 1OE=GND) level-shifts GPIO3 → LED_DATA
  through R19 470 Ω
- Antenna keepout (no copper, all layers) at the module antenna end

## GPIO16/17 double-assignment — R16/R17 0Ω links

The frozen pin map uses GPIO16 for both ENC_B and UART0 TX0, and GPIO17
for both I2S_SCK and UART0 RX0. R16 (ENC_B↔TX0) and R17 (I2S_SCK↔RX0)
are 0 Ω links, fitted by default. **Flash firmware via native USB-C**
(USB-Serial-JTAG on GPIO12/13) — no UART adapter needed. For classic
UART0 flashing via J5, remove R16/R17 (or accept encoder/I2S contention
while the programmer is attached). Documented on the schematic (title
block notes) and here.

## ADC button ladder (GPIO0, 12-bit)

Topology: +3V3 —10 kΩ (R11)— GPIO0 node; each button shorts the node to
GND through its ladder resistor:

| Button | R | Voltage | ADC (0–4095) | Threshold band |
|---|---|---|---|---|
| UP | 0 Ω (R12) | 0.000 V | 0 | < 369 |
| DN | 2.2 kΩ (R13) | 0.595 V | 738 | 369–1023 |
| LF | 4.7 kΩ (R14) | 1.055 V | 1308 | 1023–1678 |
| RT | 10 kΩ (R15) | 1.650 V | 2048 | 1678–2430 |
| OK | 22 kΩ (R18) | 2.269 V | 2813 | 2430–3454 |
| none | — | 3.300 V | 4095 | > 3454 |

## Assembly / mechanical notes

- **INMP441 (U2)** is a bottom-port LGA (4.72×3.76 mm): the PCB has an
  Ø0.8 mm sound-port hole under the package. Reflow strongly
  recommended; hand-soldering is hostile (no exposed pad edges). Do not
  plug the port hole with solder.
- **SHT31** footprint is the real DFN-8 2.5×2.5 mm package.
- **TFT module** on J1 (2×7 header) may overhang the board edge —
  mechanical note only; confirm clearance in the enclosure.
- EC11 switch pins are NC (push = use OK button instead).
- TFT backlight: GPIO2 via R9 100 Ω, R10 10 kΩ pull-down keeps the
  backlight off during reset.

## Routing status

Rev 1.0 ships with **no routed tracks/vias**: all nets are ratsnest
(a full-board GND pour on B.Cu plus small per-net marker pours on F.Cu
document the net set). A previous auto-routing attempt produced cross-net
collisions, so routing is deliberately deferred to interactive work in
KiCad (or a verified autorouter pass). Power rails must be routed at
≥ 0.5 mm when done. The generator self-checks pad/courtyard clearances
geometrically and the kicad-happy analyzer reports **0 cross-net
(DFM-001) violations**.

## Analyzer notes (kicad-happy triage)

- PM-002 BT1/BT2 0.75 mm from board edge: intentional (left-edge button
  column); >= 0.5 mm fab clearance held.
- TE-001 no test points: prog header J5 + module pads serve as access.
- TV-001 no thermal vias on U1 EP: EP is ground-paddle soldered;
  C6 module dissipation is modest; add via-in-pad if thermals matter.
- PU-001 SHT31 ALERT/RESET NC by design (not used).
- RS-001 +5V/LED_5V/VBUS "no declared source": rails enter via USB-C /
  screw terminals (connectors are the sources).
- DS-002: datasheets/ sync is handled by the repo-level parts pipeline.

## Flashing

1. Hold BOOT (BT2), tap EN (BT1), release BOOT → download mode.
2. `esptool.py --chip esp32c6 write_flash ...` via the USB-C port
   (native USB-Serial-JTAG), or `esphome run esphome/ledhub-c6.yaml`.
3. UART0 header J5 (+3V3/TX0/RX0/GND) only with R16/R17 removed.
