# presencepro-c3 — mmWave presence + lux node (45 × 35 mm)

ESP32-C3-WROOM-02 node with HLK-LD2410(B) 24 GHz presence radar (1×5
header), BH1750 ambient-light sensor, USB-C (native USB + power), EN/BOOT
buttons, power + status LEDs and a 1×4 programming header.

License: MIT. KiCad 8 project, generated by `gen_presencepro_c3.py`
(`python3 gen_presencepro_c3.py`; exits non-zero on any validation
problem).

## Features

- ESP32-C3-WROOM-02 (4 MB flash), custom footprint verified against the
  official Espressif KiCad library (18.0 × 20.0 mm body, 1.5 × 0.9 mm pads
  @ 1.5 mm pitch, columns x = ±8.75, EP pad 19; antenna at pin-1/top end)
  — `github.com/espressif/kicad-libraries/.../ESP32-C3-WROOM-02.kicad_mod`
  + Espressif module datasheet.
- Antenna keepout (no copper, all layers) over the module antenna area.
- USB-C: D−/D+ → GPIO18/19 via 22 Ω (R5/R6), 5.1 kΩ CC pull-downs
  (R3/R4), VBUS → R10 0 Ω → +5V → AP2112K-3.3 → +3V3.
- HLK-LD2410(B) on J1 (5V / TX / RX / OUT / GND); radar is 5 V-powered,
  UART + OUT are 3.3 V logic.
- BH1750 (U2) at 0x23, 4.7 kΩ pull-ups R1/R2.
- EN button BT1 (R7 10 kΩ pull-up, C6 100 nF), BOOT button BT2 → GPIO9.
- Power LED D1 (R8 1 kΩ), status LED D2 on GPIO10 (R9 1 kΩ).
- Prog header J2: +3V3 / TX0 (GPIO21) / RX0 (GPIO20) / GND.

## Pin map (SPEC 4.2)

| Function | ESP32-C3 GPIO |
|---|---|
| Radar: MCU RX ← radar TX / MCU TX → radar RX | 4 / 5 |
| Radar OUT (occupancy) | 3 |
| I2C SDA / SCL (BH1750) | 6 / 7 |
| USB D− / D+ | 18 / 19 |
| BOOT button / EN | 9 / EN |
| Status LED | 10 |
| UART0 RX0 / TX0 (prog header J2) | 20 / 21 |

Strapping pins: GPIO9 = BOOT (internal pull-up, button to GND). OUT is
read on GPIO3 (a strapping pin on the C3, but the LD2410 drives it
deterministically after boot; acceptable per SPEC).

## Routing status

Rev 1.0 ships with **no routed tracks/vias**: all nets are ratsnest
(full-board GND pour on B.Cu; small per-net marker pours on F.Cu document
the net set). A previous dense hand-routing pass failed geometric
self-check, so routing is deferred to interactive work in KiCad (route
power at ≥ 0.5 mm). The generator self-checks pad/courtyard clearances
geometrically and the kicad-happy analyzer reports **0 cross-net
(DFM-001) violations**.

## Analyzer notes (kicad-happy triage)

- TE-001 no test points: prog header J2 + module pads serve as access.
- TV-001 no thermal vias on U1 EP: EP is ground-paddle soldered; C3
  dissipation is modest; add via-in-pad if thermals matter.
- RS-001 VBUS/+5V "no declared source": rails enter via the USB-C
  connector (connectors are the sources).
- DS-002: datasheets/ sync is handled by the repo-level parts pipeline.

## Flashing

1. Native USB-C (USB-Serial-JTAG on GPIO18/19) — `esptool.py --chip
   esp32c3` or `esphome run esphome/presencepro-c3.yaml`; auto-reset via
   USB enumeration, or hold BOOT (BT2) + tap EN (BT1) manually.
2. UART0 header J2 (+3V3/TX0/RX0/GND) with an external 3.3 V UART as
   fallback.
