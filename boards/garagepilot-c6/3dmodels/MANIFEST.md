## Notes

* The `ESP32-C6-WROOM-1.STEP` model was obtained from the Espressif KiCad library as `ESP32-C6-WROOM-1U.STEP`.  The `-1U` variant differs only by the addition of a U.FL antenna connector; the shield, body, and castellated-pad geometry are identical to the on-PCB-antenna `ESP32-C6-WROOM-1` used on this board.  The local file was renamed to match the BOM footprint.
* All KiCad packages3D models use the standard [KiCad library license](https://www.kicad.org/libraries/license/) (CC-BY-SA 4.0 with the Design Exception).  The Espressif library uses the same license terms; see its [LICENSE.md](https://github.com/espressif/kicad-libraries/blob/main/LICENSE.md).
* Models were verified by loading the populated board in KiCad's 3D viewer and in the `kicad-cli pcb render` outputs saved under `images/`.
